# Leuk Spaans Leren

An interactive web application designed to help Dutch speakers learn Spanish at A1 level.

## About the project

Leuk Spaans Leren is a personal front-end development project that combines language learning with interactive web technologies.

The goal is to create an accessible learning experience where beginners can study Spanish through short lessons, native-speaker audio recordings, and interactive exercises.

## Planned Features

- Spanish A1 lessons explained in Dutch
- Vocabulary and pronunciation exercises
- Audio recordings by a native Spanish speaker
- Interactive quizzes with immediate feedback
- Learning progress tracking
- Responsive design for desktop and mobile

## Tech Stack

- JavaScript
- HTML
- CSS
- Vite

## Project Status

In development — October 2026.

The first version will focus on the A1 level, starting with greetings, pronunciation, and basic introductions.

Features will be developed and added incrementally.
